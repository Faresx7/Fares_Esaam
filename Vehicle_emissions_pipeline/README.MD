## Vehicle Emissions ML Pipeline

- this project works with **RandomForestRegressor** to predict vehicle emission based on data previously trained.

# Goal from project
- To gain hands-on knowledge of pipelines and apply them myself for a deeper understanding.

# - steps
1. Load data
2. Define x, y
3. Specify numeric and categorical columns
4. Create pipeline for cleaning data (using: "simpleimputer","StandardScaler","OneHotEncoder")
5. Combine pipelines (using: "ColumnTransformer")
6. Create final pipeline
7. Split data to Train & Test
8. Train model
9. Create prediction
10. Evaluate Model

# Tech
- python (pandas,numpy)
- Sklearn
